* **Gun1**: Welder 1, tool number 1, servo gun, additional axis 2 -> 需要设置伺服工具参数
* **Gun2**: Welder 1, tool number 2, servo gun, additional axis 1 -> 需要设置伺服工具参数

* **Gun4**: Welder 1, tool number 4, servo gun, additional axis 1 -> 需要设置伺服工具参数
