# 4.5.5 고정전극 위치 가변 서보건 제어

서보건 전체를 체인지하면 이를 위한 설비(ATC, 건 스텐드 등)가 필요하지만 이동전극은 고정하고 고정전극을 체인지하는 시스템을 만들어 운영하면 별도의 설비가 필요하지 않고 체인지시 소요되는 시간도 절약할 수 있습니다. 이를 지원하기 위해서는 고정전극의 수만큼 마모량과 소프트 리밋을 관리해야 하므로 용접건 체인지(서보툴 체인지) 기능과 유사한 동작이 필요합니다. 따라서 해당 기능의 사용에 앞서 용접건 체인지(서보툴 체인지) 기능을 먼저 학습하십시오.

본 기능이 서보건 체인지 기능과 다른점은 기계적으로 전기적으로 접속 분리 동작을 수행하지 않는다는 것이며 또한 모터와 엔코더 정보는 항상 동일하므로 이 정보들은 갱신하지 않습니다.

<br>

```python
S10   move L, ...                   #고정전극 1을 이동
      toolchng fixed,tg=G1,is=di1   #고정전극 1로 변경처리
S11   move L, ...                   #로봇이동
      spot gun=1,cnd=1, seq=1       #건번호 1로 용접 수행
S12   move L, ...                   #고정전극 2를 이동
      toolchng fixed,tg=G2,is=di1   #고정전극 2로 변경처리
S13   move L, ...                   #로봇이동
      spot gun=2,cnd=2, seq=2       #건번호 2로 용접 수행
```
