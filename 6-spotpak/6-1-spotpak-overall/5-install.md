# 6.1.5 설치 방법



스폿팩(SPOTPAK)은 plug-in 방식으로 개발되었습니다. TP에 표시되는 내용은 html, javascript 로 작성되었고, python 프로그램과 통신하며 사용자의 작업 요청을 main 프로그램으로 전달합니다. 제공되는 SW 는 본 메뉴얼에서 설명하는 모든 기능을 담고 있으나, 사용자의 요구에 맞게 수정하여 사용가능합니다. 아래 절차를 참고하셔서 plug-in 프로그램을 설치하시기 바랍니다.

<br>

[설치 순서]

 - 1. 'spotpak' 플러그인 프로그램을 USB 에 저장합니다.
 - 2. USB 를 TP에 연결합니다.
 - 3. 서비스 > 5: 파일 관리 > USB > 'spotpak' 폴더 > 복사
 - 4. MAIN > apps > 붙여넣기
 - 5. 제어기 재부팅
 - 6. 시스템 > 5: 응용 파라미터 > SPOTPAK
