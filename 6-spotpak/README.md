# 6. Spot-Pak



Spot-Pak 是现代机器人公司用于点焊的集成控制系统的名称。
本手册描述了焊机与机器人控制器之间接口相关的设置，以及 TP（教导示教器）操作。

<br>

{% hint style="info" %}
 * 从 ${cont_model} V60.28 官方发布版开始提供。
 * 目前支持三种焊机：Chowel、Obara 和 Hyosung。
{% endhint %}
