# 6. Spot-Pak

Spot-Pak是现代机器人集成控制系统，用于点焊。 本手册描述了焊接机与机器人控制器之间接口的相关设置，以及TP（教导盒）操作。

 *目前支持三种焊接机：Chowel、Obara和Hyosung。
